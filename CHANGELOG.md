# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## 2025-12-22

### Added

- **Core Agents**
  - `@challenger` - First principles thinking, assumption challenging, and decision documentation
  - `@planner` - Feature planning, architecture design, and implementation plans
  - `@builder` - TDD implementation for production-ready code
  - `@reviewer` - Code review, security analysis, and bug detection
  - `@tester` - Test generation and coverage improvement
  - `@documenter` - READMEs, API documentation, and code comments
  - `@releaser` - Changelogs, version management, and release preparation
  - `@debugger` - Root cause analysis, error diagnosis, and fixes

- **Language-Specific Rules**
  - Go language conventions and idioms for backend services
  - Python conventions for data engineering pipelines
  - React and TypeScript conventions for frontend applications

- **Core Standards**
  - Conventional commits format
  - Structured logging standards
  - Error handling philosophy
  - Quality gates checklist
